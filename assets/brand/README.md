# Rinlada Brand Assets

ไฟล์ชุดนี้พร้อมนำขึ้น GitHub ที่ `assets/brand/`

- `logo-primary.svg/png` โลโก้หลักแนวนอน
- `logo-secondary.svg/png` โลโก้แนวนอนแบบกะทัดรัด
- `logo-icon.svg/png` ไอคอนวงกลม
- `favicon-*.png` ไอคอนสำหรับเว็บและมือถือ
- `logo-dark.svg` เวอร์ชันพื้นหลังสีเขียวเข้ม

สีหลัก:
- Dark green `#173F2B`
- Green `#2F6B3B`
- Light green `#7DAA68`
- Brown `#7A4B2A`
- Gold `#C8A85B`
