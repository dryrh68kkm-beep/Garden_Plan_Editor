Garden Plan Editor

คุณสมบัติ
- กำหนดขนาดพื้นที่จริงเป็นเมตร
- Grid 0.25 เมตร และ Snap to Grid
- วาดแปลงปลูก สนามหญ้า ทางเดิน พื้นไม้ และบ่อน้ำ
- วางต้นไม้จากฐานข้อมูลตัวอย่าง
- วางไฟสนามและข้อความ
- เลือก ย้าย ลบ ทำสำเนา และจัด Layer
- แก้ไขตำแหน่ง ขนาด รัศมีทรงพุ่ม และราคา
- Undo / Redo
- บันทึกแบบเป็น JSON และเปิดกลับมาแก้ไข
- Export ผังเป็น PNG
- สร้าง BOQ อัตโนมัติ
- Export BOQ เป็น CSV
- ใช้งานแบบ Offline

วิธีใช้งาน
1. แตกไฟล์ Garden_Plan_Editor.zip
2. เปิด index.html ด้วย Chrome, Edge หรือ Safari
3. กำหนดขนาดพื้นที่แล้วกด “ปรับขนาดผัง”
4. เลือกเครื่องมือหรือกดต้นไม้ในฐานข้อมูล
5. บันทึกแบบเป็น JSON เพื่อเปิดแก้ไขภายหลัง


เพิ่มในเวอร์ชัน 2
- ปุ่มล้างผังทั้งหมด พร้อมยืนยันก่อนลบ
- แบบสวนสำเร็จรูป 6 แบบ
  1. สวนทรอปิคอล
  2. สวนมินิมอลโมเดิร์น
  3. สวนญี่ปุ่น
  4. สวนหลังบ้านพักผ่อน
  5. สวนระเบียง/คอนโด
  6. สวนริมสระ
- โหลดแบบแล้วแก้ไขตำแหน่ง ขนาด และรายการต่อได้
- BOQ อัปเดตตามแบบสำเร็จรูปโดยอัตโนมัติ


เพิ่มในเวอร์ชัน 3
- คลังแบบสวน AI อยู่ภายในโปรแกรม
- มีภาพตัวอย่างสวนทรอปิคอลและมินิมอลโมเดิร์นที่สร้างไว้
- เก็บชื่อแบบ สไตล์ ขนาดพื้นที่ ตำแหน่ง งบประมาณ ต้นไม้ วัสดุ และ Prompt
- ค้นหาและกรองตามสไตล์
- กดรายการโปรด
- ดูภาพและรายละเอียดแบบเต็ม
- โหลดผังสำเร็จรูปที่สัมพันธ์กับภาพได้ทันที
- เพิ่มรูปสวนของผู้ใช้เองและเก็บในเบราว์เซอร์
- ลบรูปที่ผู้ใช้อัปโหลดเองได้
