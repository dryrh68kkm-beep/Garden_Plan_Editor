Garden Plan Editor

คุณสมบัติ
- กำหนดขนาดพื้นที่จริงเป็นเมตร
- Grid 0.25 เมตร และ Snap to Grid
- วาดแปลงปลูก สนามหญ้า ทางเดิน พื้นไม้ และบ่อน้ำ
- วางต้นไม้จากฐานข้อมูลตัวอย่าง
- วางไฟสนามและข้อความ
- เลือก ย้าย ลบ ทำสำเนา และจัด Layer
- แก้ไขตำแหน่ง ขนาด รัศมีทรงพุ่ม และราคา
- Undo / Redo
- บันทึกแบบเป็น JSON และเปิดกลับมาแก้ไข
- Export ผังเป็น PNG
- สร้าง BOQ อัตโนมัติ
- Export BOQ เป็น CSV
- ใช้งานแบบ Offline

วิธีใช้งาน
1. แตกไฟล์ Garden_Plan_Editor.zip
2. เปิด index.html ด้วย Chrome, Edge หรือ Safari
3. กำหนดขนาดพื้นที่แล้วกด “ปรับขนาดผัง”
4. เลือกเครื่องมือหรือกดต้นไม้ในฐานข้อมูล
5. บันทึกแบบเป็น JSON เพื่อเปิดแก้ไขภายหลัง
