# อัปเดต garden-styles-data.js

ไฟล์นี้เพิ่มรายชื่อต้นไม้และข้อมูลรายละเอียดให้แบบสวนครบ 50 แบบ

- `recommendedPlants` ยังเป็น array ของชื่อไทย เพื่อไม่ให้หน้าเว็บเดิมเสีย
- `plantPalette` เป็นข้อมูลรายละเอียดสำหรับทำหน้ารายละเอียด, BOQ และตัวกรอง
- จำนวนต้นไม้ต่อแบบสูงสุด 12 ชนิด
- ราคาเป็นราคาอ้างอิงเริ่มต้นจาก plants.json และสามารถแก้ไขได้

ให้อัปโหลด `data/garden-styles-data.js` ทับไฟล์เดิมใน GitHub
