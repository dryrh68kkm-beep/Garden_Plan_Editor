# Rinlada Web Editor — Plant Database

ต่อยอดจาก V2 โดยแยกฐานข้อมูลต้นไม้ออกจาก app.js

## โครงสร้างใหม่
- index.html
- style.css
- app.js
- data/plants.json
- README.md

## ฟังก์ชันใหม่
- ฐานข้อมูลต้นไม้แยกเป็นไฟล์ JSON
- ข้อมูลเริ่มต้น 60 รายการ
- ค้นหาด้วยชื่อไทย อังกฤษ ชื่อวิทยาศาสตร์ และรหัส
- กรองตามประเภทและสภาพแสง
- ดูต้นทุน ราคาขาย ระยะปลูก และการดูแล
- ดูแบบสวนที่เหมาะสม (ใช้เป็นข้อมูลอ้างอิงสำหรับ Showcase เท่านั้น)
- ปุ่มโหลดฐานข้อมูลใหม่

## วิธีอัปโหลดขึ้น GitHub
1. อัปโหลดแทนที่ index.html, style.css, app.js และ README.md
2. สร้างโฟลเดอร์ชื่อ data ในหน้าแรกของ Repository
3. อัปโหลด plants.json เข้าไปในโฟลเดอร์ data
4. รอ GitHub Pages อัปเดต 1–3 นาที

สำคัญ: ต้องคงชื่อและตำแหน่ง `data/plants.json` ตามนี้
